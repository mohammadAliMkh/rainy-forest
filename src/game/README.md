# game — محتوای جنگل بارانی

- `world/`: زمین و مسیر، درخت‌ها، گیاهان، کلبه، گودال‌ها، بافت‌ها، حذف چیزهای بیرون از دید.
- `weather/`: آب‌وهوا (`Weather.ts`: گاهی خشک، گاهی نم‌نم، گاهی باران و به‌ندرت رگبار با رعدوبرق ملایم)، باران، مه، باد، آسمان، شبانه‌روز.
- `lighting/`: نورها، سایه، فانوس، انعکاس آسمان.
- `camp/`: دور آتش، شامل آتش، نشیمن‌ها، سایه‌بان و پارکینگ.
- `store/`: سوپرمارکت چوبی جنگل: ساختمان، قفسه‌ها و یخچال‌ها با جنس‌ها، فروشنده‌ی پیر و تابلوی مسیر. اندازه‌ها همه در `storeLayout.ts` است.
- `intro/`: معرفی سینمایی و متن آن.
- `scenario/`: سناریوها. سناریو ۱: روح پارچه‌ای، کارگردان صحنه با دوربین فیلم، و متن صحنه (جاها، زمان‌ها، نماها) در `ghostScript.ts`.
- `people/`: آدم‌ها و رفتارشان، گیتار، مشخصات دوستان؛ `Flight.ts`: ترسیدن، فرار، نفس‌نفس زدن و برگشتن یک نفر.
- `creatures/`: لونا، آهوها، پرنده‌ها و خرگوش‌ها.
- `vehicles/`: پاترول و هورنت.
- `player/`: حرکت اول‌شخص و برخورد.
- `sound/`: صداهای جنگل. به رویدادها گوش می‌دهد (قدم، گیتار، حیوانات، معرفی).

**قانون:** این پوشه از `ui` و `app` چیزی import نمی‌کند. برای خبر دادن، از گذرگاه رویداد استفاده کنید.
