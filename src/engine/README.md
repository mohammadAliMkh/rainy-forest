# engine — ابزار عمومی بازی

چیزهایی که به این جنگل خاص ربطی ندارند و در هر بازی دیگری هم به کار می‌آیند.

- `Game.ts`: حلقه‌ی اصلی؛ در هر فریم سیستم‌ها را به ترتیب اجرا می‌کند.
- `events.ts`: گذرگاه رویداد (publish / subscribe). اسم رویدادها در `config/events.ts` است.
- `render/`: رندرر و افکت‌ها، تشخیص کارت گرافیک، شیدرهای مه و باد.
- `audio/`: موتور صدای سه‌بعدی و ابزار ساخت صدا.
- `quality/`: سطح کیفیت و کیفیت خودکار. فقط با رندرر کار می‌کند و تغییر را با رویداد خبر می‌دهد.

**قانون:** این پوشه هیچ‌چیز را از `game`، `ui` یا `app` import نمی‌کند.
