# ui — صفحه‌ها و دکمه‌ها

- `UI.js`: صفحه‌ی بارگذاری و شروع، منوی تنظیمات (ذخیره در localStorage)، پیام‌ها، نوارهای سینمایی و زیرنویس.
- `Minimap.js`: نقشه‌ی کوچک گوشه‌ی صفحه.
- `TouchControls.js`: جوی‌استیک و دکمه‌های گوشی.
- `style.css`: همه‌ی استایل‌ها.

**قانون:** این پوشه از `game` و `app` چیزی import نمی‌کند. فقط داده‌ای را که `app` به آن می‌دهد نمایش می‌دهد.
